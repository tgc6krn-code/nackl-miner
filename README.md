# NACKL Miner — Telegram Mini App (каркас)

Рабочий скелет приложения. UI и логика состояний готовы и работают в
демо-режиме (без реального SDK) — можно сразу открыть в браузере и
посмотреть, как выглядит и переключается интерфейс.

## Что нужно сделать, чтобы заработал реальный майнинг

### 1. Заменить демо-заглушки на реальный SDK
В `app.js` все места с комментарием `TODO` — это точки интеграции с
`@tvmsdk/core` и Bee Engine. Нужно:
- Установить пакет: `npm install @tvmsdk/core`
- Собрать бандл (Vite/Webpack/esbuild — что удобнее), так как WASM
  через `<script>`-тег напрямую не подключается
- Сверить точные имена методов с актуальной документацией:
  https://dev.ackinacki.com/bee-engine/bee-engine-sdk-integration-documentation
  (SDK развивается, имена методов могли измениться)

### 2. Разместить на HTTPS-хостинге
Telegram Mini App требует HTTPS. Варианты (бесплатно и просто):
- **GitHub Pages** — залить папку в репозиторий, включить Pages
- **Vercel** / **Netlify** — просто перетащить папку в веб-интерфейс

### 3. Подключить домен к боту (@RusscBot)
В @BotFather:
```
/mybots → RusscBot → Bot Settings → Menu Button
```
Указать URL твоего хостинга. После этого кнопка меню в чате с ботом
будет открывать это приложение.

### 4. Получить Dapp ID
Через dev-портал `dev.ackinacki.com` — понадобится для регистрации
твоего приложения в экосистеме (нужен твой AN Wallet).

### 5. Протестировать на своём кошельке
Открыть бота → нажать «Подключить AN Wallet» → пройти реальную
авторизацию → убедиться, что тапы и сбор наград реально уходят в сеть.

## Важно по безопасности

- ⚠️ Токен бота, который ты уже получил от BotFather, **засветился в
  переписке** — рекомендую перевыпустить его через `/revoke` в
  BotFather и больше нигде не публиковать.
- Токен бота **не нужен** в этом коде вообще — он используется только
  если понадобится отдельный бэкенд с командами бота. Сама механика
  майнинга работает через AN Wallet и Dapp ID, не через Bot API.
- **Приватные mining-ключи никогда не должны покидать устройство
  пользователя** — ни в логах, ни на твоём сервере, ни в аналитике.
